Create an account-scoped Cloudflare API token with at least AI Gateway: Run
and Workers AI: Read permissions, then paste `Bearer <your API token>` into
`cloudflare_ai_gateway_api_token`. Enter the account ID that owns your AI
Gateway in `cloudflare_account_id`. See [Cloudflare's AI Gateway setup
guide](https://developers.cloudflare.com/ai-gateway/get-started/). This
template uses Alibaba Qwen 3 Max, a paid third-party model; make sure your
Cloudflare account has credits for it.
