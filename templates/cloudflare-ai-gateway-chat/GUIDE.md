Create an account-scoped Cloudflare API token with at least AI Gateway: Run
and Workers AI: Read permissions, then paste `Bearer <your API token>` into
`cloudflare_ai_gateway_api_token`. See [Cloudflare's AI Gateway setup
guide](https://developers.cloudflare.com/ai-gateway/get-started/). Set
`cloudflare_ai_gateway_endpoint` to your account's full `/ai/v1` endpoint.
